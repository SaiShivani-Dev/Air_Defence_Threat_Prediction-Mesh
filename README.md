# Air_Defence_Threat_Prediction-Mesh
AI/ML powered Aerospace and Air defense threat prediction mesh.

⚙️ Algorithms & Their Roles:

1.Linear/Multiple Regression → Predict fuel usage, altitude drift, missile trajectory deviation.

2.Logistic Regression → Classify radar signals (hostile vs friendly).

3.Feature Engineering → Create new features like turbulence index, drone swarm density.

4.KNN Classifier → Detect anomalies by comparing telemetry to historical safe vs hostile patterns.

5.Decision Tree → Transparent rules for commanders (e.g., drone altitude + speed → kamikaze threat).

6.Cross Validation → Ensure robustness across datasets.

7.SVM → Handle stealth aircraft detection with overlapping radar signals.

8.Naive Bayes → Fast classification of pilot incident reports or intercepted comms.

9.Logic Gates → Encode defense rules (e.g., missile trajectory aimed at base → trigger defense shield).

10.Perceptron → Lightweight binary classifier for onboard edge devices.

11.Backpropagation → Train deep neural nets for multi-modal fusion (radar + telemetry + biometrics + weather).

12.K-Means Clustering → Group threats into clusters (routine aircraft, suspicious drone swarm, missile trajectory).
